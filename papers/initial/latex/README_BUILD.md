# ReCheck ICASSP-format research draft

Run `pdflatex -interaction=nonstopmode -halt-on-error main.tex` twice in this folder. No BibTeX run is needed. All tables, numeric macros and figures are included. Main PDF is supplied.

This is a controlled-model draft, not a submission-ready real-LLM study. Real author names, affiliations, ORCID, scientific review and further experiments are still required. Keep the AI disclosure.

The spconf executable definitions were transcribed from the official ICASSP2027 web text; this is not a byte-identical downloaded upstream archive. Check the latest official template before final submission.
Official source: https://cmsworkshops.com/ICASSP2027/papers/PaperFormat/spconf.sty

Full reproducibility and raw data are in ICASSP_Research_Package.zip.
