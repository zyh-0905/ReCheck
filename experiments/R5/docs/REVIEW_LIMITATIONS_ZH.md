# R5 研究审查与限制
全部结果为离线规则工具执行，0模型调用；不称真实LLM新实验。
校准/验证/评测目录种子不重叠；仍共享同一个环境生成器，不能称跨域。
完整风险核不稳定优于单通道影响模型，置信区间主要跨0。
已知转移与准确校准使结果不能直接推广到开放世界。
损失后果模型从校准数据学习，不估计新的危险率或未知语义。
只测3个语义通道和最多8步；规模试验不能证明高维可扩展性。
标准Bellman与基础扰动界不是独立的新一般算法理论。
源代码及数学由同一助手复核，未获得独立人类审查。
用户本地复现同一数据只增加可复现性/硬件计时证据，不增加独立样本数。
