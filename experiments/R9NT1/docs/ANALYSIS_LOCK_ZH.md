# R9NT1结果分析口径

本说明在新协议真实数据采集前固定，不是外部预注册。R9TQ1资格结果已知，本轮据其整合接口，不据未来方法胜负选择样本。

1. 所有32主回合、4重复分开；计划数、完整数、部分数、未启动数分别列，不给未完成者填0或100%。
2. 四种评分保持原R9含义：任一写工具成功、最终目标、最终业务状态、全过程安全目标。终止单列。逐例核查差异来源，避免将字段豁免或环境事件当作代理恢复。
3. R9TQ1仅证明三项接口可运行，不认证模型权重，也不增加本轮样本。旧R9/R9J1四条失败、R9TQ1十条资格响应分别保留，不作为本轮结果。
4. 公共材料与工具能力相同，提示组增加指令长度，没有等长安慰剂。只描述有根据的配对行为差异，不把点估计自动说成因果优势。
5. 多工具批次整体验证、逐项执行。读取后事件可在同一模型响应的后续写入之前发生。报告模型轮次与工具索引，不声称模型在同批中间看过结果并重新决定。
6. scheduled/triggered/missed分别报告；全组结果为主，按触发者筛选仅作条件性诊断。不得强插未触发事件或删掉不利任务。
7. 第一份有效研究响应记录当前元数据，后续变化暂停。和资格响应指纹的跨批差异只记录，不认证同权重，不拿旧身份文件顶替。
8. 成本：主/重复、两组，按请求数、工具外层调用、输入/输出/推理/缓存tokens、延迟和墙钟分组。推理若在输出内不重复相加；缺失费用保持UNKNOWN，不能将探测/调用数当货币。
9. 主终点无增益或全对：保留天花板，停止同模板扩样。存在弱评分接受误写：核对原用户意图、原评分与完整证据，再作为有限诊断。不能把已知TOCTOU或路径评测重新命名为新算法。
10. 这轮四模板、单后端、单端点仍不足以自动支撑ICASSP投稿；不更改现有R8论文结果，待核查后再补实际证据。RepairLens无新结果。
