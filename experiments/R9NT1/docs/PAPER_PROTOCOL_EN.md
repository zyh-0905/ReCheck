Calls are validated as a complete batch and dispatched in returned order; batches are neither parallel nor atomic. An external change occurs after the first qualifying pre-write read and before the next native tool, which can belong to the same model response. That read's genuine result is not rewritten. The actor cannot adapt a later call in the same generated batch to an earlier result. We explicitly record this case rather than treating a model response as a single atomic tool action.

This measures metadata consistency, not weight identity. Previous qualification observations are not incorporated into study endpoints.

Termination, exceptions, event exposure, within-response event/write co-occurrence and complete cost accounting are separate. All scheduled cases are retained; exposure is behavior-dependent, not randomized.
