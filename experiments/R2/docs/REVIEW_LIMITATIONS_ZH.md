# 审查与限制
本轮研究端完成：给定模型策略区分检查、审核器回归、计费未知处理、
请求账本暂停规则、用户执行CLI、原始响应离线重建与完整本地HTTP fixture链路。
未完成：任何R2真实模型实验、独立人类审稿、通用自然语言依赖抽取、学习漂移、
公开benchmark原生对照、论文确认性统计或论文重新编译。
原有v0.1测试和源文件被保留以检查兼容性，不意味着其旧审查逻辑成为R2主审核。
所有新主调用只走r2.py，旧pilot/report.py仅用于保留的旧测试。
同一助手进行了代码与证据审核；没有可用的独立子代理/人类复核。
R2模型请求沿用有界SQL任务；不能把这次工具集成升级包装为新的算法理论。
本地实际测试环境为Linux / CPython3.13.5 / numpy2.3.5；
Windows/macOS提供命令形式但没有在两系统实机验证。
本容器包含无关的sitecustomize预热钩子；最终洁净测试以Python -S、
显式加载已安装依赖执行，避免它打印无关电子表格错误。
此隔离不用于隐藏任何本项目测试失败；早期失败与之后通过的日志均保留。
