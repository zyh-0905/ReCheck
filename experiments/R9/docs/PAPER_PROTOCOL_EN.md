# Prospective development protocol — NOT results

R9 asks whether coarse observations and path-sensitive state constraints disagree on the same on-policy continuation. Sixteen constructed cells cross four intent templates with four one-shot update schedules in the pinned ToolSandbox backend. A scheduled post-read update occurs after the first qualifying successful pre-write read, not after every read or based on whether the actor is about to fail. The authentic read result is retained. Agents can make further tool calls and stop normally. Episodes without the qualifying pre-write read remain unexposed and are reported rather than discarded.

Two prompts share the native tool whitelist and ten-request limit. Neither receives a commit guard, hidden event label, true state, or grader result. We score successful mutation returns, final goal achievement, final business-state cleanliness, and goal achievement without any earlier unauthorized write separately. Creation timestamps automatically changed by reminder modification are excluded from the declared business-state projection; other task fields are not. A later repair cannot erase a path violation. The main diagnostic is grading disagreement within a trace, not a claimed new defense.

The study plans 32 primary and four repeated episodes on one endpoint. Repetitions do not replace primary outcomes. All 16 cells share four templates and one backend, so neither the episode count nor the request count represents that many independent task distributions. No real R9 responses have been collected by the researcher at package release. Native rule trajectories and local HTTP fixtures are separately labeled software/mechanism tests. Existing TOCTOU and trajectory-evaluation work is acknowledged; publication-level novelty remains unestablished.
