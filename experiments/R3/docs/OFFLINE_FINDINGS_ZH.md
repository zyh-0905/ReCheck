# R3离线研究结果与放行依据

**性质：实际执行的精确有限模型计算，不是真实LLM结果，不是货币成本，不是新的一般定理。**

本轮先排查R2的低效实验设计，再将两项问题拆开：调度的净价值与模型计划执行的误差。新的公开输入去除无关字段和核验时间戳，由确定性程序呈现SQLite结果；这改变了系统架构，不能把R3与R2原始成功率直接比较。

## 1. 全部预定配置均保留

执行了288组配置，每组评估5个固定方法。匹配假设时DP优势由其模型内最优性解释，作用是可行性诊断，不足以支撑新颖性。漂移失配和无变化对照也全部报告。

## 3. 有效处理机会

固定的16条任务类型流中，ReCheck/Myopic合计有45个不同刷新动作位置。按照各条件声明的漂移模型，任务相关语义差异数的期望总和为20.757270。这是对可能隐藏状态的期望，不是选出一个有利的具体隐藏状态。

预检查未生成或读取真实模式、正确答案和LLM响应。付费流的种子不因最终胜负或是否恰好变化而替换，所有条件输出都回传。

## 4. 模型执行实验的变化

16条流，每流12个任务，ReCheck/Myopic各一个LLM计划调用，共384次主调用。每流第6个任务每个方法另独立重复一次，共32次。第一份响应始终为主结果；不进行best-of-two，重复诊断开销单列且保留在实际总费用中。一次smoke后合计417次。

初始记忆由两个实际校准收据解码，不声称学会写记忆。计划仅输出所需字段；工具结果已完成过滤，数值由程序呈现，不再让LLM对计数再次加减。应用于所有方法，旧实验不重评分。

## 5. RepairLens推进边界

根据旧readiness实测，诊断选择费用超过避免重算的费用。新增条件性净成本门槛：只有诊断上界+剩余修复上界小于直接重算下界时才选择诊断；缺可靠边界默认重算。代码与测试已提供，但历史点估计不是未来有效上界，也没有新的RepairLens真实模型成绩。

## 6. 如何决定后续

先检查原始日志与分母，再按条件区分相关语义、计划错误、输出重复波动及成本。效果不好也接受数据。成功仍不能替代公开任务、不同模型、未知漂移学习和原生近邻对照；经典可加DP的新颖性问题未解决。不要把本轮开发结果写成已满足ICASSP录用要求。

## 7. 软件验证与证据

原R2的6个失败案例作为审核回归而非新结果。新增穷举小问题验证精确期望；新接口、缓存、导出LICENSE、调用上限、暂停、同输入不同ID、部分导出和离线重建均有测试。具体测试数量和最终分发包哈希以R3_Delivery_Verification.json为准。软件模拟请求不是真实LLM调用。
