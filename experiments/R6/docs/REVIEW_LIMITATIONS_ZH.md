# 执行与研究审查边界

R6增加的是可核对的校准成本和选择性标签获取实验，并未解决所有原始论文目标。使用原样R5规划器和原样R4工具；不存在新的通用DP定理或生产API实测。

**监督边界：**训练期故意设置已知语义并运行工作流，允许读取训练答案。该监督被计费并只在调用purchase时产生。评测期未知语义和答案只交给环境与审核，不交给选择器/规划器。选择器不能先看全量核再声称只买了16个条目。公共相关通道由规范给出，不是学习发现。

**获取规则：**decision采用参考网格上的两个极端损失情景(0/1)，评估立即最优动作是否值得变化；不是针对未来任务的精确VOI，不是贝叶斯后验或置信区间。occupancy是同一个网格中当前动作对条目的概率权重，不是测得的真实部署访问频率。固定网格、两菜单平均及常数都是开发设计选择。

**统计边界：**四个独立训练批次，每批16个目录；每个拟合批次的评测流独立。共享菜单/单项菜单是同一数据的两种处理；不同方法和同一流步骤高度相关。配对区间在训练批次内按流重采样，是条件性、描述性结果；不认证训练分布总体结论，不做多重假设确认性p值。

**负面结果：**决策敏感选择没有稳定超越随机或网格访问权重。数据变化下可能不如单项核。少测标签不等于本地更快，决策选择的计算可能比全部标签执行贵。全量核不是被保证更好的真实模型。不能为了改善结论增加种子或换配置。

**成本边界：**每学习器参考答案运行单独计数；16/32模型的成本是独立部署各自所需前缀，不可将两个前缀重复加总成物理执行数。所有诊断/审核再执行都是验证开销，不是新增科学样本。实际本地时间另报。lambda与N成本敏感性是设定，不是人民币、真实API账单或未来部署保证。

**验证：**同一研究助手的自审加独立算术实现，不是独立人类同行评审。原始文件SHA只证明字节完整性，不能证明操作者所有历史行为。跨平台浮点诊断有窄范围容差，离散输出不放宽。

**本阶段停止条件：**若在相同预算下不能稳定超过随机/简单选择，暂停该选择器的优越性主张；不要立即投入新的字段复制LLM实验。需要新的理论/现实困难和明确实验再继续。RepairLens暂无新增主算法证据。
