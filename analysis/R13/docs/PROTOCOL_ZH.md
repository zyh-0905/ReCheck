# R13：公开任务的时序范围清点与合法回退负对照

日期：2026-09-15。阶段：探索性离线研究。延续已批准的R12后续计划；不启用模型、不改上游、不改旧成绩、不写远端仓库。

## 目的
1. 按固定源码枚举全部基础任务，分清增强变体、任务文字、模拟用户隐藏规格、状态目标及自动guardrail。结构清点不是自动语义认证。
2. 对公开任务作可审查的候选分类：信息获取、终态效果、过程前置状态、分阶段/用户修订、信息不足/禁止事件。无独立人工确认，不声称金标准。
3. 在原始多轮“朋友→敌人→朋友”任务上检查合法目标撤回。这是检验“把所有目标都要求终态成立”修补法的负对照，而非诱导LLM犯错。
4. 检查公开完整轨迹的可获得性；没有合格轨迹时分母为0/不可估计，不以README样例或旧自建任务冒充公开复现。

## 范围与计数
上游固定ToolSandbox c8571d7854316d2e1c5f288e59fe1e34e53f6dd1，R12只读输入。先枚举，再明确标注源码启发式与逐例可执行规则的区别。基础注册项仍含同义改写及多轮派生，不称独立领域。
新脚本选择公开的 twice_multiple_user_turn 场景：correct_revision、missing_final_revision、undo_latest_goal、no_effect、redundant_error_then_revision。如新增恢复/前置状态诊断，单列探索性补充。每条原始评分始终独立保存。
回退由脚本使用实际工具产生；用户话语按公开模拟用户规格脚本化，非新LLM回合。局部时序谓词的输入为公开任务、修订消息边界、实际状态，不借原分数选择真假。
R12的45条旧轨迹只作为固定回归材料，不增加样本量。

## 三值范围检查
在有限轨迹有效区间上分别检查曾经成立、区间末成立、区间内始终成立。未知输入不默认成功；显式退役的旧目标在其区间末检查，而非最终对话终点。此为常规有限时序逻辑实现，不声称新算法或理论。

## 完成门槛
原始合法修订能通过；忽略最新目标不能被“曾经完成第一项”掩盖；错误回执不自动当状态违反；无证据不估计自然模型错误率。代码、表格、失败与限制均保留。只有自然模型测量协议和费用范围另行冻结后才交接用户。
