# Template provenance

Official source used: https://cmsworkshops.com/ICASSP2027/papers/paper_kit.php
Style URL: https://cmsworkshops.com/ICASSP2027/papers/PaperFormat/spconf.sty
Retrieved on 2026-09-12 using web text extraction. Direct download from the execution container failed (DNS/network unavailable), so executable style definitions were transported from the inspected official source. Introductory comments were shortened. This is not a claimed byte-identical upstream archive.

The sample PDF linked by the **2027** Paper Kit still says **2026** in its title. We followed the actual 2027 page and its supplied style rather than a third-party IEEEtran template.

Official IEEEbib URL (not redistributed here): https://cmsworkshops.com/ICASSP2027/papers/PaperFormat/IEEEbib.bst
The papers use explicit numeric IEEE-style `thebibliography` entries, so no substitute bibliography style or network download is needed to compile.

The official Paper Kit specifies non-blind review, author metadata, ORCiD for every author, no page numbers, embedded fonts, <=5 MB PDF and maximum four technical pages. The website gives a stricter references-only fifth page; both drafts keep their fifth page references-only and AI disclosure within the technical pages.
