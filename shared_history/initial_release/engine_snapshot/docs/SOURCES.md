# Primary-source register

Checked through web/Exa on 2026-09-12. The register supports related-work and format statements; it is not evidence that all upstream systems were reproduced. Contemporary arXiv entries are cited as preprints unless a formal venue is explicitly verified. Paper excerpts are not republished in this archive.

## Conference requirements and template

- ICASSP2027 Author Guidelines: https://2027.ieeeicassp.org/author-guidelines/ — maximum4 technical pages and optional references-only fifth page; AI-generated content disclosure.
- Paper Submission Instructions: https://2027.ieeeicassp.org/paper-submission-instructions/
- Full Paper Kit: https://cmsworkshops.com/ICASSP2027/papers/paper_kit.php — page geometry, font and electronic submission requirements. The main author page is stricter on page5 than the detailed kit; this package uses references only on page5.
- Official style source: https://cmsworkshops.com/ICASSP2027/papers/PaperFormat/spconf.sty — executable definitions transcribed through web text because direct container download failed. Header comments shortened; local file is not byte-identical to upstream. See upstream/provenance.json.
- Current call: https://2027.ieeeicassp.org/call-for-papers/ — regular full-paper deadline16 September2026. Time and any changes must be checked again before submission.

## ReCheck bibliography

1. Ali Maatouk, Mohamad Assaad, Anthony Ephremides. The Age of Incorrect Information: an Enabler of Semantics-Empowered Communication. https://arxiv.org/abs/2012.13214 — initial2020 record, revised2022. Classical semantic freshness connection, not a new agent method.
2. Xingkun Yin, Hongyang Du. GLOVE: Global Verifier for LLM Memory-Environment Realignment. https://arxiv.org/abs/2601.19249 ; code https://github.com/NICE-HKU/GLOVE — memory/environment probing baseline; not executed here.
3. Mayur Akewar, Ravi Ranjan. SafeCommit: Certifying When Memory-Grounded Agents May Safely Act. https://arxiv.org/abs/2608.04289 ; code https://github.com/akewarmayur/SafeCommit — action certification and targeted probes. Its controlled release does not itself establish a deployed LLM result.
4. Susheel Suresh, Hazel Mak, Sahil Bhatnagar, Chhaya Methani, Alejandro Gutierrez Munoz. Grounding Agent Memory: Environment-Probing Curation for Enterprise Agents. https://arxiv.org/abs/2609.11060 — post-task environment-informed curation; not reproduced here.
5. Kazuki Nakayashiki. When Stale Constraints Go Unchecked: Budgeted Verification Failures in Inherited Agent Memory. https://arxiv.org/abs/2608.25553 — nearby fixed-budget allocation diagnosis and simple target-blind rule.
6. Daniel Golovin, Andreas Krause, Debajyoti Ray. Near-Optimal Bayesian Active Learning with Noisy Observations. Advances in Neural Information Processing Systems23,2010,pp766–774. https://papers.nips.cc/paper_files/paper/2010/hash/1e6e0a04d20f50967c64dac2d639a577-Abstract.html ; https://arxiv.org/abs/1010.3091 — classical active-test/EC2 lineage.

## RepairLens bibliography

1. David Heckerman, John S. Breese, Koos Rommelse. Troubleshooting Under Uncertainty. Microsoft Research Technical Report MSR-TR-94-07,1994. https://www.microsoft.com/en-us/research/publication/troubleshooting-under-uncertainty/
2. John S. Breese, David Heckerman. Decision-Theoretic Troubleshooting: A Framework for Repair and Experiment. https://arxiv.org/abs/1302.3563 —2013 is the archival arXiv date, not a claim that decision-theoretic troubleshooting originated then.
3. Golovin, Krause, Ray, above — information-based comparison methods are local declared instantiations, not proof that the original theorem automatically applies to productive repair.
4. Ruoling Qi, Xuaner Wu, Penghang Liu, Jian Chen, Yirui Liu. REVISE: Validity-Guided Recovery for Online Revisions in Agent Workflows. https://arxiv.org/abs/2609.00643
5. Jaineet Shah. Causal Agent Replay: Counterfactual Attribution for LLM-Agent Failures. https://arxiv.org/abs/2606.08275 ; https://github.com/jaineet17/causal-agent-replay
6. Bingjie Li, Yumeng Song, Zhongming Yao, Tianyi Li. Localizing Emergent Failures in Agentic AI: Recovering Minimal Repair Families via Counterfactual Replay. https://arxiv.org/abs/2608.29228
7. Zhongwen Luan, Xiaoyu Zhang, Ming Hu, Yue Yang, Jiongchi Yu, Xiaohong Chen. Repair or Resample? Rethinking Failure Debugging in LLM Multi-Agent Systems. https://arxiv.org/abs/2608.25920
