# 给本地代码助手：R9NT1固定真实模型批次

请仅执行本目录的`R9NT1_LIVE_NATIVE_TOOL_CONTINUATION_01 / r9nt-1.0.0`。研究端已完成离线测试，用户只需真实模型步骤及回传。不要设计新实验、修改代码/参数/模型/种子/评分、替换工具接口、自动修复输出或根据结果重新采样。

## 目录与环境
1. 使用新`R9NT1_Research_Kit`根目录，不覆盖R9TQ1、R9J1或更早目录。程序叫`r9nt.py`，不是旧`r9.py`或`r9tq.py`。
2. 需要Python3.11.x。已有正确依赖的旧虚拟环境可复用其解释器绝对路径，仅执行新目录脚本。不搜索密钥、不复制旧runs/PREPARED。依赖清单固定；不要用3.13或NumPy2强改源码。
3. 阅读README。仅当需要时安装requirements；不额外运行研究端整套离线实验。

## 状态优先
运行`<python3.11解释器> r9nt.py status`并检查新目录状态。
- main不存在：执行prepare；通过后才进行下述唯一付费命令。
- completed：只audit/export。
- paused/running/孤立账本/遗留锁：不恢复、不删锁，确认无写入进程后只尝试audit/export；保留错误并回传，不另开副本。
如果此前执行过R9NT1，不能因为用户再次说继续就获得新配额。

## 唯一付费操作
```bash
<python3.11解释器> r9nt.py run --confirm-calls 360
```
没有smoke或qualify，不调用/models、curl、SDK探针、其他模型或账户接口。最多360次请求、每回合10次，每响应4个工具、每回合40个工具；提前完成即停。

密钥由用户在本地LLM_API_KEY或终端隐藏提示中输入。不得要求用户发到助手聊天，不读取.env、不放命令行、不回显。
运行失败不修提示、不调上限、不换模型、不抽取散文JSON或再请求补答案。非零退出也要保留原始响应。

## 回传
结束或暂停后执行：
```bash
<python3.11解释器> r9nt.py audit
<python3.11解释器> r9nt.py export
```
上传最后的`uploads/R9NT1_feedback_*.zip`。audit失败仍导出，不把机械pass写成研究胜利。若导出因遗留锁或凭据扫描拒绝，保留原目录并报告报错，不删除保护或伪造ZIP。

不需要另写“根因/实验成功”报告；可附实际退出码与ZIP路径。不要误称本地模拟短信是真实短信。研究端收到后负责核查、统计、论文和是否进入下一阶段。当前包不自动追加任何实验或投稿。
