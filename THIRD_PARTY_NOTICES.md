# Third-party notices and research-data scope

This repository is an archival collection. No new blanket license is applied to
third-party source, datasets, recorded model outputs, manuscript text, or their
original licenses. Keep each original LICENSE, NOTICE, data card and attribution.

- ToolSandbox source snapshots retain the upstream Apple license and notices.
- SAP/agent-quality-inspect data is accompanied by its original data card declaring
  Apache-2.0. Source repository, dataset revision and original collection hashes are
  recorded in the dataset directory and the R14/R15 reports. The archive contains
  publicly released research records, not a new API-generated benchmark run.
- Inherited spconf style and bibliography/source files remain as supplied in the
  manuscript package. The archive does not certify them as a fresh official-template download.
- Shared early research packages retain their original RepairLens parts only for
  provenance and original relative imports; those results are not ReCheck evidence.
- Standalone fonts, R7 Python runtimes and binary dependency distributions are not
  redistributed. PDF embedded fonts remain part of the original PDF documents.
- No private key, token, .env, virtual environment or unrelated project is intended
  for publication. Pattern-based scanning does not certify all privacy/IP rights.

The owner is responsible for choosing a license for newly authored research code
and text, after checking authorship and third-party requirements. Do not label the
entire archive MIT/Apache merely because one included dataset has that license.
