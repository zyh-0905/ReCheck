# R7公开运行材料下载包：不安装、不运行实验

## 为什么需要这一步
研究助手已经尝试直接下载ToolSandbox和依赖，但运行容器的GitHub/PyPI DNS访问失败；连接器能读取源码，却不能直接安装所需二进制包。本脚本只负责把公开文件搬到可上传的ZIP。**之后的安装、原生工具测试、规则基线和统计仍由研究助手完成，不需要你复跑离线实验。**

当前已完成源码契约测试，未执行ToolSandbox原生环境。不要把材料下载成功当作原生实验成功。

## 你只需运行一次

解压到新目录，进入包含collect_materials.py的文件夹。

macOS/Linux：
```bash
python3 collect_materials.py --allow-public-downloads
```
Windows：
```powershell
python collect_materials.py --allow-public-downloads
```

使用已有Python3.10或以上。不需要pip、虚拟环境、GPU、API Key或账号。不要执行下载的Linux程序。

回传终端最后打印的：
```text
uploads/R7_materials_<UTC时间>.zip
```

它只包含公开源码、运行时、包发布元数据、分发文件、脚本及摘要清单。若为INCOMPLETE_DOWNLOAD，也回传现有ZIP，不修改检查结果或换版本。

## 内容与核验

- ToolSandbox提交：c8571d7854316d2e1c5f288e59fe1e34e53f6dd1。
- 源码ZIP根据内容和文件模式重建Git tree，必须匹配64ccd1694a91f2029844434d5995a2c0945cd6b2；只计算，不解压到系统。
- Linux x86_64 CPython3.11.14：固定发布资产与SHA256；即使你的电脑是Mac/Windows，也保持此目标。
- 固定版本CPU工具/评测依赖：读取各版本PyPI JSON，选择Linux CPython3.11/兼容abi3/通用wheel；仅rouge-score允许源码分发下载，不在你的机器上构建。

- 一些导入依赖包含模型SDK的类型定义，但本脚本不导入/安装它们，不接触模型客户端或密钥。
- 单文件150MiB、总下载450MiB上限；不是固定文件大小估计。最终以报告为准。
