# R7材料反馈的有限更正

1. README写“Python3.9.6满足3.10+”不成立。这是版本解释错误，不表示有效下载文件必须重采。当前采集脚本没有在入口强制该版本条件；研究端认可的是逐字节核对后的材料，不认证用户解释器版本。
2. 53个依赖分发文件为52个wheel与1个rouge-score源码分发，不是53个wheel。
3. “没有读取任何环境变量”不宜作绝对陈述。脚本未主动读取模型密钥，但urllib的系统代理/TLS处理可能使用环境设置。没有据此发现密钥泄漏；包内摘要核对不能认证机器所有环境访问。
4. 下载报告的packages_installed=false与downloaded_code_executed=false只描述用户收集阶段。研究端随后确实完成了离线安装与原生执行，新的证据单独保存，不改写下载报告。
5. 本轮不将材料收集、33个新增测试或4个手工动作通路当成真实LLM实验；原生执行器另外两项失败继续保留。

无需用户修改原README或重新提交。
