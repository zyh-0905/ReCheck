# R6：选择性交互校准与真实采样成本
版本r6-6.0.0，协议R6_SELECTIVE_CALIBRATION_01。**本轮零LLM/API实验调用。**研究端已经执行固定离线实验；你的任务是同一实验的跨机器复现与成本记录，不增加独立样本。

## 为什么做本轮
R5的单项影响核来自完整校准表，尚未实际节省数据获取。R6让每个学习器有自己的按需校准账本：只测单项、测全部、随机追加、按参考网格访问权重追加、按立即决策敏感性追加。未购买的标签不会传给选择器。研究端发现决策敏感规则并未稳定超过随机选择，不能修改数据把它跑成胜利。

## 安装及执行
解压到全新的R6_Research_Kit，不覆盖R1—R5。Python3.11+，numpy==2.3.5，无需GPU、Docker、LaTeX、API Key或账号。依赖安装可能访问包索引，实验命令禁用网络。

macOS / Linux：
```bash
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m unittest discover -s tests -v
.venv/bin/python r6.py execute
```
Windows PowerShell：
```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
.\.venv\Scripts\python.exe r6.py execute
```
可以使用已安装同版本NumPy的Python环境，但不要改旧工程。
`execute`依次进行prepare → 固定训练/实验 → 独立审核 → export。不要给整个命令设置过短的执行时限。不存在smoke或模型配置步骤。

## 本轮固定规模
- 4个互不重叠的校准批次，每批16份目录，共64份。每条校准标签是真正执行规则工作流获得的监督。
- 82个非冗余单项条目、100个额外交互条目。每条购买对应16次带指定语义的工作流；每学习器另外支付80次正确参考工作流。公共无关变量的等价性、零失配损失为结构契约，不假装是采样得到。
- 单项1392次；全量2992次；追加16条为1648次；追加32条为1904次。都是单一模型独立部署时的校准工作流次数，不是人民币/API额度。
- 随机、访问权重、决策敏感三个选择器都保存16/32嵌套检查点。16检查点不能看到之后16次购买的标签；两个检查点共享过去，不能把两者成本相加当成实际独立运行。
- 实际训练总执行40384次（包含1600次正确参考）；没有预先计算全表再假装部分购买。
- 128条独立评测基础流，四种条件，每流8任务；两菜单同数据配对，10种策略，2560轨迹、20480条规则记录。每条件32条流，条件于4个拟合批次；多方法/多菜单不是新增独立样本。
- 选择器只使用单项/已购买标签和固定的假想公共状态网格。当前目录、真实模式、任务正确答案都不进入在线调度。当前工具输出也不更新其信念，这是范围限制。

## 错误或中断
保留错误、失败、旧文件和锁。不要换seed、阈值、数据、预算、源码、参考哈希，不强制解锁，不创建第二次运行挑选较好耗时。不完整run不会自动续跑；audit/export仍可回传诊断。完整run再次execute不会产生新的研究轨迹，但audit仍会重新计算验证，不能把审核执行计成新增实验样本。

## 跨平台验收
1. 文件传输/源码/协议：原始SHA-256；2. 动作、预算、答案、绑定等：类型和值严格一致；3. 仅records[*].predicted_task_error_after_receipts允许有限[0,1]浮点绝对差1e-14、相对容差0；4. 计时与规划缓存大小单列。选择器诊断score只在指定selection条目允许1e-12绝对差；其选中的条目必须完全相同。
不能全局四舍五入，也不能把一侧删除字段后继续比较另一侧旧哈希。源码/样本/动作不同会暂停科学验收，不能通过放宽所有浮点门槛解决。

## 费用和科学边界
运行期J=任务失败+.05×核验额度。共同初始化6额度单列。`cost_frontier.csv`另外展示假想代价lambda和部署次数N下的摊销J，包括相同的0.3初始化项；它不是实际货币或已测部署节约。选择器设计、选择运算、标签执行、冷启动规划和后续执行各自计时，不把少采标签自动写成更快。
源代码和全部结果已冻结为开发协议，不是外部预注册。相同R4 API，不是公开benchmark或跨领域迁移。只测3个语义通道、已知漂移，不承诺普遍安全、强统计保证或录用。不同方法的状态分布不同，按策略分组的预测误差不能直接当作独立校准能力排名。
本轮没有新增RepairLens实验。下一步是否继续这个选择器，需要研究审查，不自动扩大运行。
